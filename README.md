# 🌐 Ecosistema de Innovación INTEIA

Este proyecto tiene como objetivo centralizar toda la información del ecosistema de investigación e innovación de INTEIA en una plataforma web interactiva y organizada. Surge a partir de un archivo Excel donde actualmente se registran manualmente las fuentes y recursos clave.

---

## 🎯 Objetivo del Proyecto

Diseñar y desarrollar una plataforma digital donde se pueda:

- Visualizar fuentes de información del ecosistema (organizaciones, recursos, investigaciones, etc.)
- Consultar y filtrar datos por categorías
- Subir nuevas fuentes desde un formulario
- Gestionar la información de forma dinámica

---

## 🧩 Estructura del Repositorio

/frontend → Interfaz de usuario (React, HTML, CSS, etc.)
/backend → Lógica del servidor, API, base de datos
/data → Excel original y datos de prueba
/docs → Prototipos, manuales, documentación técnica
